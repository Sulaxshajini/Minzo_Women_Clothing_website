## 📖 About the Project

**Minzo** is a front-end women's clothing e-commerce website designed to deliver a clean, modern, and elegant shopping experience. The site showcases a curated collection of women's fashion — from casual wear to formal outfits — with a focus on visual appeal, smooth navigation, and responsive design across all devices.

This project was built as a static website using only HTML, CSS, and JavaScript — no frameworks or back-end required.

---

## ✨ Features

- 🎨 **Elegant UI** — Clean, fashion-forward design tailored for a women's clothing brand
- 📱 **Fully Responsive** — Optimized for desktop, tablet, and mobile screens
- 🛍️ **Product Showcase** — Organized product listings with images, names, and prices
- 🔍 **Category Navigation** — Browse by clothing category (e.g. tops, dresses, accessories)
- 🛒 **Shopping Cart UI** — Interactive cart interface built with JavaScript
- 💌 **Newsletter Section** — Email subscription section for promotions
- 🌟 **Featured & New Arrivals** — Highlighted sections for trending and new products
- 📞 **Contact Page** — Reach-out form for customer inquiries

## 🚀 Getting Started

Since this is a static website, no installation or server setup is needed.

### Option 1 — Direct Browser Open

1. **Clone or download the repository**
   ```bash
   git clone https://github.com/Sulaxshajini/Minzo_Women_Clothing_website.git
   ```

2. **Extract the zip file**

   Unzip `WomenClothing Minzo.zip` to a folder of your choice.

3. **Open in browser**

   Navigate to the extracted folder and open `index.html` in any modern browser:
   ```
   Double-click index.html  →  Opens in your default browser
   ```

### Option 2 — Live Server (Recommended for Development)

If you're using VS Code, install the **Live Server** extension and click **"Go Live"** for hot-reload during editing.
